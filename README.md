## 🧠 认知科学学习法四部曲

1. **晨间/午间输入（知识储备）**：
   - 深入教材（Griffiths、陈鄂生、同济、吉米多维奇、武忠祥、李永乐）；
   - 在 `01_高等数学_604`、`02_量子力学_811`、`03_考研英语_201` 中建立**原子化笔记（Atomic Cards）**。
2. **傍晚实战（每日大赛）**：
   - 打印或平板打开 `05_每日大赛_Daily` 的当日 PDF；
   - 闭卷进入**心流五部曲**：Page 2 默写破冰 $\to$ Page 3 限时做 M1/Q1 $\to$ Page 4 对照解析挑刺 $\to$ Page 5 复盘沉淀。
3. **夜间闭环（双链反哺）**：
   - 在 `05_每日大赛_Daily` 当日复盘笔记中，使用 `[[知识点]]` 链接回知识储备库，沉淀易错陷阱。
4. **多巴胺升级（持续动力）**：
   - 查看 [[00_Mission_Control_主控台]] 与 [[02_多巴胺成长系统_SkillTree]]，领取当日经验值，防御学习动量！
