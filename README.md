## 🧠 认知科学高效学习五部曲 (Cognitive Engine)

1. **晨间热机（主动提取 · 30min）**：
   - 杜绝被动翻书，拿出白纸盲推昨日核心公式与前 3 天错题（Error-driven learning）。
2. **日间超日节律攻坚（90min 深度块）**：
   - 严格遵循 90min 深度工作 + 15min 屏幕隔离休息；
   - 切换至 **交错练习 (Interleaving)**，数理与英语交错穿插，锻炼模式识别敏锐度。
3. **遇到困难即时求助（AI 导师脚手架）**：
   - 依据 `[[99_System_认知系统与模板/00_AI协作规范与智能导师工作流]]`，向 AI 索取费曼白话直觉、视频切片推荐或单步微推导。
4. **晚间巅峰实战（每日大赛闭卷 · 80min）**：
   - 打印或平板打开 `05_每日大赛_Daily` 的当日 XeLaTeX PDF，闭卷手撕，红笔挑刺入库。
5. **睡前突触巩固与元认知（20min）**：
   - 填写 `[[tpl_每日元认知反思日志]]` 完成 3 分钟自我归因；
   - 睡前草稿纸盲写政治/量力公式，利用慢波睡眠完成无意识神经巩固。
