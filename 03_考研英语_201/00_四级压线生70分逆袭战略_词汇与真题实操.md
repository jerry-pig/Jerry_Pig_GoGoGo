## 🔍 二、 四级 428 分阅读理解“保命三板斧”（专治看不懂长文章）

你觉得“阅读理解不行”，通常是因为**试图读懂全文每一个单词**，导致工作记忆过载而大脑死机。考研阅读是**逻辑辨析，不是英汉翻译**！

### 斧法 1：【题干精准定位法（绝不跨段找答案）】
- 考研阅读 5 道题绝大多数**严格对应文章的 5 个自然段（细节题顺序原则）**。
- 读文章前，先圈出 5 道题干里的**大写专有名词、时间年份、核心术语**；
- 带着题干定位词直接跳进对应段落，找到包含定位词的那 1~2 句话（定位句），答案 90% 就在这里！

### 斧法 2：【主干铅笔手术法（消灭长难句恐惧）】
- 遇到超过 3 行的长难句，不要慌，立刻拿出铅笔做“物理切除”：
  1. 遇到 `that / which / who` 引导的从句 $\to$ **打括号 `( ... )` 括起来先不读**；
  2. 遇到双逗号 `, ... ,` 或双破折号 `-- ... --` 插入语 $\to$ **直接划横线跳过**；
  3. 遇到 `although / while / because / if` 状语 $\to$ **打中括号 `[ ... ]`**；
  4. **只读剩下的主语 + 谓语动词 + 宾语！** 句子瞬间缩短成 5 个单词，核心意思一目了然！

### 斧法 3：【选项防坑黄金铁律】
- **同义替换是正确答案的灵魂**：正确选项通常把原文词换成了它的同义近义词或高度概括词。
- **照抄原文多陷阱**：如果某个选项跟原文一字不差，尤其是长得很像原文原句的，80% 是偷换概念的迷惑项！

## ✍️ 三、 作文功能积木（石雷鹏带写法的威力）

1. **不要整篇死背，只背“功能句积木”**：
   - 原因阐释功能句：`Primary among these factors is that [主谓宾], which inevitably leads to [名词短语].`
   - 举例论证功能句：`A case in point is that [具体例子], which serves as a typical mirror of this issue.`
   - 个人建议功能句：`From my perspective, it is imperative for [主语] to take effective measures to [动词原形].`
2. **填词游戏**：无论题目考“人工智能”、“传统文化”还是“网络沉迷”，只要往功能句积木里填入核心名词，阅卷老师看到的是高级结构，直接给 14+ 分高分！
