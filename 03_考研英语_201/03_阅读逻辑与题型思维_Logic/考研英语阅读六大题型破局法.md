# 考研英语阅读六大题型逻辑与诱导项排除法

> **所属模块**：[[00_英语通关导引_MOC]]  
> **核心命题逻辑**：考研英语阅读考察的**不是英汉翻译**，而是**学术论证逻辑与批判性思维**！阅读 4 篇文章共 40 分，得阅读者得天下。

---

## 🎯 一、 考研命题人最经典的 4 大诱导陷阱 (Distractor Traps)

在排除错误选项时，严密比对以下 4 种典型漏洞：

1. **偷换概念 / 张冠李戴 (Subject Distortion)**：
   - 选项用了原文原词，但把 A 的性质安到了 B 身上，或者替换了核心动词（例如：原文是“可能减缓”，选项变成“彻底根除”）。
2. **反向对立 / 正反倒置 (Reversal of Polarity)**：
   - 原文作者持怀疑批评态度，选项说“完全赞同”；原文加了双重否定，选项变肯定。
3. **过度延伸 / 主观臆断 (Over-generalization / Extrapolation)**：
   - 出现绝对化词汇：`all, never, exclusively, completely, the only`。考研学术论文倾向于“谨慎保留”的措辞（如：`may, tend to, likely, partially`）。
4. **答非所问 / 无中生有 (Irrelevant Truth)**：
   - 选项本身内容符合常理甚至也是真理，但在原文中根本没有出现，或者与题干问的核心不相干。

## 🔍 二、 六大核心题型拆解与突破法

### 1. 细节理解题 (Fact / Detail Question)
- **题干特征**：`According to paragraph X... / ...because...`
- **破局三步法**：
  1. 找准**题干定位词**（专有名词、时间、特征动词）；
  2. 回原文定位到**具体句子（定位句）**；
  3. 寻找**同义改写（Synonym Replacement）**。正确答案 90% 都是原文核心词的同义词替换，凡是原词一字不差的往往是诱导陷阱！

### 2. 主旨大意题 (Main Idea / Title Question)
- **题干特征**：`The text mainly discusses... / Which of the following is the best title?`
- **破局要领**：
  - **串读首尾段与各段首句**；
  - 寻找全文**复现率最高的“核心话题词（Topic Word）”**；
  - 避开以偏概全（只讲了第二段的细节不能作为全篇标题）。

### 3. 推理判断题 (Inference Question)
- **题干特征**：`It can be inferred from the text that... / We learn from the last paragraph that...`
- **破局要领**：
  - 考研的“推断”其实是**“弱推断（微言大义）”**，本质依然是原文的改写；
  - **切忌自己脑补三步**！只要从原文往前推半步即可，推得越远越容易掉入命题人陷阱。

### 4. 词汇与指代题 (Vocabulary in Context)
- **题干特征**：`The word "..." (Line X, Para. Y) most probably means...`
- **破局要领**：
  - 考研考的一定不是你第一反应想到的常规词义；
  - **看该词所在句子的上下文逻辑关系**：如果是并列/递进，找同义词；如果是转折（however, but），找反义词。

### 5. 观点态度题 (Author's Attitude)
- **题干特征**：`The author's attitude towards... is...`
- **红宝书态度词库**：
  - **常客（正态度）**：`objective (客观), cautious / reserved (谨慎保留), supportive (支持), realistic (务实)`；
  - **常客（负态度）**：`skeptical (怀疑), critical (批评), doubtful (质疑)`；
  - **极少选（极端/不负责态度）**：`indifferent (漠不关心), unconcerned (不关心), prejudiced (偏见), enthusiastic (狂热盲目)`。

### 6. 例证题 (Example / Illustration Question)
- **题干特征**：`The author mentions ... in Para. X in order to / to show...`
- **破局要领**：
  - 例子本身千万不要选！**例子是仆人，论点是主人**；
  - 答案永远在例子**前面的论点句**或**后面的总结句**中！
