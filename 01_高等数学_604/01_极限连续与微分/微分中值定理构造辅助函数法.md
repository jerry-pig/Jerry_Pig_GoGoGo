## 🎯 一、 四大中值定理逻辑定位与选用决策树

```
                          ┌────────────────────────────────┐
                          │    中值定理大题证明决策树      │
                          └────────────────────────────────┘
                                          │
            ┌─────────────────────────────┼─────────────────────────────┐
            ▼                             ▼                             ▼
    【单一中值 $\xi$ 导数型】       【双中值 $\xi, \eta$ 关联型】   【高阶导数 $f^{(n)}(\xi)$】
    优先构造 $F(x)$ 用 Rolle       分别在 $[a,c],[c,b]$ 用         直接写出带有拉格朗日余项
    或微分方程原函数还原法         Lagrange 或全区间用 Cauchy      的 Taylor 展开式！
```

| 定理名称 | 核心条件 | 结论形式 | 几何与代数直觉 |
| :--- | :--- | :--- | :--- |
| **零点定理** | $f(x) \in C[a,b]$, $f(a)f(b)<0$ | $\exists \xi \in (a,b), f(\xi)=0$ | 连续曲线穿过 $x$ 轴必有交点 |
| **Rolle 定理** | $f \in C[a,b], D(a,b)$, $f(a)=f(b)$ | $\exists \xi \in (a,b), f'(\xi)=0$ | 连续且端点等高，中间必有水平切线 |
| **Lagrange 中值定理** | $f \in C[a,b], D(a,b)$ | $f(b)-f(a)=f'(\xi)(b-a)$ | 割线斜率等于某处瞬时切线斜率 |
| **Cauchy 中值定理** | $f,g \in C[a,b], D(a,b), g'\neq 0$ | $\frac{f(b)-f(a)}{g(b)-g(a)}=\frac{f'(\xi)}{g'(\xi)}$ | 参数曲线割线斜率等于切线斜率 |
| **Taylor 中值定理** | $f$ 在邻域内有 $n+1$ 阶导数 | $f(x)=\sum_{k=0}^n \frac{f^{(k)}(x_0)}{k!}(x-x_0)^k + R_n(x)$ | 用多项式全局逼近，拉格朗日余项控误差 |

## 🛠️ 二、 辅助函数构造 5 大黄金母型（微分方程还原法）

很多同学证明大题卡在“想不到辅助函数”，本质是因为没有掌握**微分方程积分因子逆推法**！

### 1. 指数衰减/增长型：$f'(\xi) + k f(\xi) = 0$
- **逆推思维**：两边同乘积分因子 $e^{kx} \implies e^{kx}f'(x) + k e^{kx}f(x) = [e^{kx}f(x)]' = 0$
- **构造辅助函数**：
  $$F(x) = e^{kx}f(x)$$

### 2. 变系数函数型：$f'(\xi) + g'(x)f(\xi) = 0$
- **构造辅助函数**：
  $$F(x) = e^{g(x)}f(x)$$

### 3. 幂函数权值型：$x f'(x) + n f(x) = 0$
- **逆推思维**：两边同乘 $x^{n-1} \implies x^n f'(x) + n x^{n-1}f(x) = [x^n f(x)]' = 0$
- **构造辅助函数**：
  $$F(x) = x^n f(x)$$

### 4. 乘积导数商值型：$\frac{f'(\xi)}{f(\xi)} + \frac{g'(\xi)}{g(\xi)} = 0 \iff f'(\xi)g(\xi) + f(\xi)g'(\xi) = 0$
- **构造辅助函数**：
  $$F(x) = f(x)g(x)$$

### 5. 分式导数商值型：$\frac{f'(\xi)}{f(\xi)} - \frac{g'(\xi)}{g(\xi)} = 0 \iff f'(\xi)g(\xi) - f(\xi)g'(\xi) = 0$
- **构造辅助函数**：
  $$F(x) = \frac{f(x)}{g(x)}$$

## 📝 三、 典型国科大真题风格母题精解

### 【经典母题】
设函数 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0)=0, f(1)=1$。  
证明：对任意常数 $k \in \mathbb{R}$，必存在 $\xi \in (0,1)$，使得：
$$f'(\xi) + k f(\xi) = k$$

### 【标准推导步骤】
1. **移项化零**：目标式等价于 $f'(\xi) + k[f(\xi) - 1] = 0$。
2. **构造辅助函数**：令 $g(x) = f(x) - 1$，则目标化为 $g'(\xi) + k g(\xi) = 0$。根据指数型母型，构造：
   $$F(x) = e^{kx} g(x) = e^{kx}[f(x) - 1]$$
3. **验证 Rolle 条件**：
   - 连续性与可导性：$F(x)$ 在 $[0,1]$ 上显然连续，在 $(0,1)$ 内可导；
   - 端点值：
     $F(0) = e^0 [f(0) - 1] = 1 \times (0 - 1) = -1$；  
     $F(1) = e^k [f(1) - 1] = e^k \times (1 - 1) = 0$。
     *(端点值不相等！此时需要寻找中间零点！)*
4. **利用介值定理/零点定理补齐端点**：
   - 由 $f(0)=0, f(1)=1$，且 $f(x)$ 连续，根据介值定理，必存在 $c \in (0,1)$，使得 $f(c) = 1$；
   - 此时考察区间 $[c, 1]$：
     $F(c) = e^{kc}[f(c) - 1] = 0$；  
     $F(1) = e^k[f(1) - 1] = 0$。
5. **应用 Rolle 定理**：
   - $F(x)$ 在 $[c,1]$ 上满足罗尔定理条件，故 $\exists \xi \in (c,1) \subset (0,1)$，使得 $F'(\xi) = 0$；
   - 而 $F'(x) = k e^{kx}[f(x)-1] + e^{kx}f'(x) = e^{kx}[f'(x) + k f(x) - k]$；
   - 因为 $e^{k\xi} \neq 0$，所以必有 $f'(\xi) + k f(\xi) = k$。证毕！

## ⚠️ 四、 避坑手记与高分要诀

1. **区间开闭性规范**：连续性写在**闭区间** $[a,b]$，可导性写在**开区间** $(a,b)$，中值 $\xi \in (a,b)$ 必须严格落在开区间内！
2. **两中值题切忌混用**：若题目出现两个中值 $\xi, \eta$，通常意味着要在两个不同子区间 $[a,c]$ 和 $[c,b]$ 上分别应用 Lagrange 中值定理，切忌在同一区间共用一个 $\xi$。
3. **出现二阶导数 $f''(\xi)$**：90% 的解法是在端点或极值点处将函数按 **Taylor 公式展开到二阶**！
