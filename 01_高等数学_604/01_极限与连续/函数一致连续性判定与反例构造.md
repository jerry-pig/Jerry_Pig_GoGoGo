## 🎯 一、 核心定义与 $\epsilon-\delta$ 语言

### 1. 连续 vs 一致连续的本质差异
设函数 $f(x)$ 定义在区间 $I$ 上：
- **逐点连续 (Pointwise Continuity)**：
  $$\forall x_0 \in I, \ \forall \epsilon > 0, \ \exists \delta(\epsilon, x_0) > 0, \ \text{当 } |x - x_0| < \delta \text{ 且 } x \in I \text{ 时，有 } |f(x) - f(x_0)| < \epsilon$$
  *(注：$\delta$ 不仅依赖于精度 $\epsilon$，还强烈依赖于选取的参考点 $x_0$)*
- **一致连续 (Uniform Continuity)**：
  $$\forall \epsilon > 0, \ \exists \delta(\epsilon) > 0, \ \forall x_1, x_2 \in I, \ \text{当 } |x_1 - x_2| < \delta \text{ 时，有 } |f(x_1) - f(x_2)| < \epsilon$$
  *(注：**同一个 $\delta$ 必须在整个区间 $I$ 上对所有点统一步调成立！** 曲线坡度绝不允许无限变陡)*

### 2. 费曼大白话直觉 (Feynman Intuition)
> **“连续”**就像在山路上漫步：你在平缓处迈大步，在悬崖边迈碎步，只要每一步能站稳就行；  
> **“一致连续”**则是在整个山区行走时，**发给你一把全区域通用的尺子 $\delta$**。只要两点间距小于 $\delta$，无论你走到哪里，高度差绝对不会超过 $\epsilon$。这意味着**函数图像的斜率绝不能在某些局部发生爆炸或无限振荡！**

## 🛠️ 二、 一致连续性判定的三大黄金定理与判据

### 1. 闭区间 Cantor 定理（最强判定充分条件）
若函数 $f(x)$ 在**闭区间 $[a, b]$ 上连续**，则 $f(x)$ 在 $[a, b]$ 上**必一致连续**。
- **数学本质**：由有限覆盖定理（Heine-Borel 定理）保证，闭区间的紧致性（Compactness）消除了局部无限变陡的可能。

### 2. 导数有界判据（开区间/无穷区间最实用的充分条件）
若 $f(x)$ 在区间 $I$ 上可导，且**导数有界**（即存在常数 $M > 0$，使得 $\forall x \in I, |f'(x)| \le M$），则 $f(x)$ 在 $I$ 上**必一致连续**。
- **一行动量证明**：由 Lagrange 中值定理，任取 $x_1, x_2 \in I$，有：
  $$|f(x_1) - f(x_2)| = |f'(\xi)| |x_1 - x_2| \le M |x_1 - x_2|$$
  对任意 $\epsilon > 0$，只需取 $\delta = \frac{\epsilon}{M}$，即可满足定义！

### 3. 开区间端点有限极限判据（充要条件判定）
设 $f(x)$ 在**有限开区间 $(a, b)$ 上连续**，则：
$$f(x) \text{ 在 } (a, b) \text{ 上一致连续} \iff \text{左右两端点有限极限 } \lim_{x\to a^+} f(x) \text{ 和 } \lim_{x\to b^-} f(x) \text{ 均存在}$$
- **推论**：若端点极限之一为 $\infty$ 或振荡不存在，则在 $(a, b)$ 上**必不一致连续**！

## ⚠️ 三、 考研高频经典反例库 (Fatal Traps)

| 反例函数 $f(x)$ | 区间 $I$ | 是否一致连续 | 致命原因剖析与数学证明 |
| :--- | :---: | :---: | :--- |
| **$f(x) = \frac{1}{x}$** | $(0, 1)$ | ❌ **否** | 端点极限 $\lim_{x\to 0^+} \frac{1}{x} = +\infty$。取 $x_n = \frac{1}{n}, y_n = \frac{1}{2n}$，当 $n\to\infty$ 时 $|x_n - y_n|\to 0$，但 $|f(x_n)-f(y_n)| = n \to \infty$。 |
| **$f(x) = \sin\left(\frac{1}{x}\right)$** | $(0, 1)$ | ❌ **否** | 虽有界（$[-1, 1]$），但 $x\to 0^+$ 时**无限剧烈振荡**，极限不存在。取 $x_n = \frac{1}{2n\pi+\pi/2}, y_n = \frac{1}{2n\pi}$，差距趋于 0，高度差恒为 1。 |
| **$f(x) = x^2$** | $[0, +\infty)$ | ❌ **否** | 导数 $f'(x) = 2x$ 在无穷远处无界。取 $x_n = n + \frac{1}{n}, y_n = n$，间距 $|x_n-y_n| = \frac{1}{n} \to 0$，但差值 $|x_n^2 - y_n^2| = 2 + \frac{1}{n^2} > 2$。但在任何有限区间 $[0, A]$ 上均一致连续！ |
| **$f(x) = \sqrt{x}$** | $[0, +\infty)$ | ✅ **是** | 导数在 $x=0$ 处无界（$f'(x) = \frac{1}{2\sqrt{x}} \to \infty$），但根据定义，$[0, 1]$ 上由 Cantor 定理一致连续；$[1, +\infty)$ 上导数有界一致连续；拼合后全区间一致连续！ |
| **$f(x) = \sin(x^2)$** | $[0, +\infty)$ | ❌ **否** | 函数有界，但导数 $2x\cos(x^2)$ 振荡频率越来越高，波峰与波谷距离 $\Delta x \to 0$，非一致连续。 |

## 📝 四、 3 分钟极速避坑手记
1. **看到“闭区间 $[a,b]$ + 连续”**：想都别想，直接断定**一致连续**（Cantor 定理保驾护航）！
2. **看到“有限开区间 $(a,b)$”**：先看两个端点单侧极限存不存在且有限。存在就是，不存在就不是！
3. **看到“无穷区间 $[a, +\infty)$”**：
   - 导数有界 $\implies$ 一致连续（如 $\sin x, \cos x$）；
   - 若 $x\to+\infty$ 时斜率爆炸（如 $x^2, e^x, x\sin x$）或振荡加快（如 $\sin(x^2)$） $\implies$ 非一致连续。
