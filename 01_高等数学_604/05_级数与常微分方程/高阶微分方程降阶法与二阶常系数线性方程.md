## 🎯 一、 可降阶的高阶微分方程两大解法（换元降维）

当方程阶数高于一阶时，若方程缺少自变量或因变量，可令 $p = y' = \frac{dy}{dx}$ 将其降为一阶方程求解：

### 1. 不显含因变量 $y$ 型：$y'' = f(x, y')$
- **换元法则**：令 $p = y'$，则 $y'' = \frac{dp}{dx} = p'$。
- **降阶后方程**：$p' = f(x, p)$（关于 $x, p$ 的一阶常微分方程）。
- **求解流程**：求出 $p = \phi(x, C_1)$，再对 $x$ 积分一次：$y = \int \phi(x, C_1) dx + C_2$。

### 2. 不显含自变量 $x$ 型：$y'' = f(y, y')$（极高频核心考点）
- **换元法则**：令 $p = y'$，关键在于对 $x$ 求导时利用**链式法则将自变量转化为 $y$**：
  $$y'' = \frac{dp}{dx} = \frac{dp}{dy} \cdot \frac{dy}{dx} = p \frac{dp}{dy}$$
- **降阶后方程**：$p \frac{dp}{dy} = f(y, p)$（关于 $y, p$ 的一阶常微分方程）。
- **求解流程**：解出 $p = g(y, C_1)$，再由 $\frac{dy}{dx} = g(y, C_1)$ 分离变量积分：$\int \frac{dy}{g(y, C_1)} = x + C_2$。

## 📐 二、 二阶常系数齐次线性微分方程：$y'' + p y' + q y = 0$

解的结构由对应的**代数特征方程** $r^2 + p r + q = 0$ 的判别式 $\Delta = p^2 - 4q$ 唯一决定：

| 特征根 $r_1, r_2$ 的性质 | 判别式 $\Delta$ | 齐次方程通解 $Y(x)$ 表达式 | 物理模型与图像直觉 |
| :--- | :---: | :--- | :--- |
| **两个不相等的实根** $r_1 \neq r_2$ | $\Delta > 0$ | $Y(x) = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ | 过阻尼衰减 / 指数增长 |
| **两个相等的实根** $r_1 = r_2 = r$ | $\Delta = 0$ | $Y(x) = (C_1 + C_2 x) e^{r x}$ | 临界阻尼运动 |
| **一对共轭复根** $r_{1,2} = \alpha \pm i\beta$ | $\Delta < 0$ | $Y(x) = e^{\alpha x} (C_1 \cos\beta x + C_2 \sin\beta x)$ | 欠阻尼振动 / 简谐振荡 |

## ⚡ 三、 二阶常系数非齐次线性微分方程：$y'' + p y' + q y = f(x)$

根据**线性方程解的叠加原理**，非齐次方程的通解为：
$$y = Y(x) + y^*(x) \quad (\text{对应齐次通解 } Y + \text{非齐次特解 } y^*)$$

### 待定系数法求特解 $y^*$ 规则手册（自由项为 $e^{\lambda x} P_m(x)$ 型）：
当自由项为 $f(x) = e^{\lambda x} P_m(x)$（$P_m(x)$ 为 $m$ 次多项式）时，特解设法为：
$$y^*(x) = x^k Q_m(x) e^{\lambda x}$$
其中 $Q_m(x)$ 为与 $P_m(x)$ 同次的待定多项式，指数 $k$ 由 $\lambda$ 是否为特征根决定：
- 若 $\lambda$ **不是**特征方程的根，取 $k = 0$；
- 若 $\lambda$ 是特征方程的**单根**，取 $k = 1$；
- 若 $\lambda$ 是特征方程的**二重重根**，取 $k = 2$。

## 🚀 四、 降维核武：微分算子法 $D$（秒杀待定系数法）

传统“待定系数法”需要设特解、求一阶导、求二阶导、代入原方程联立方程组求未知数，计算繁琐且极易算错。**微分算子法（Operator Method）** 直接将微分运算代数化，特解一步写出！

### 1. 核心算子符号与运算法则
记求导算符为 $D = \frac{d}{dx}$，二阶导为 $D^2 = \frac{d^2}{dx^2}$。二阶常系数线性方程可写为：
$$(D^2 + pD + q) y = f(x) \iff F(D) y = f(x)$$
特解直接写为**逆算子形式**：
$$y^* = \frac{1}{F(D)} f(x)$$

### 2. 四大神级算子计算公式（必背秒杀秘籍）

#### 秘籍 1：指数移位公式（非共振型 $F(\lambda) \neq 0$）
若 $F(\lambda) \neq 0$（$\lambda$ 不是特征根），直接把 $D$ 换成实数 $\lambda$：
$$\frac{1}{F(D)} e^{\lambda x} = \frac{1}{F(\lambda)} e^{\lambda x}$$

#### 秘籍 2：指数共振与移位定理（共振重根型，彻底替代待定系数 $x^k$）
若 $F(\lambda) = 0$（$\lambda$ 是特征根），利用**指数移位定理 (Exponential Shift)**：
$$\frac{1}{F(D)} [e^{\lambda x} v(x)] = e^{\lambda x} \frac{1}{F(D + \lambda)} v(x)$$
- **当 $v(x) = 1$ 且 $\lambda$ 为 $k$ 重特征根时**：
  $$F(D) = (D - \lambda)^k G(D) \implies y^* = e^{\lambda x} \frac{1}{(D + \lambda - \lambda)^k G(D + \lambda)} \cdot 1 = e^{\lambda x} \frac{1}{D^k} \left[ \frac{1}{G(\lambda)} \cdot 1 \right] = \frac{x^k}{k! \cdot G(\lambda)} e^{\lambda x}$$
- **刚才第三关真题秒杀实录**：
  $$(D^2 - 4D + 4) y = 3e^{2x} \iff (D - 2)^2 y = 3e^{2x}$$
  $$y^* = \frac{1}{(D - 2)^2} 3e^{2x} = 3 e^{2x} \frac{1}{D^2} (1) = 3 e^{2x} \left(\frac{x^2}{2}\right) = \frac{3}{2} x^2 e^{2x}$$
  *(耗时 5 秒，无需设 $Ax^2e^{2x}$ 求导再比对系数！)*

#### 秘籍 3：三角函数算子代换（$D^2 \to -\omega^2$）
对于 $\sin(\omega x)$ 或 $\cos(\omega x)$，**直接将所有的 $D^2$ 替换为 $-\omega^2$**（注意只换偶数次幂，保留奇数次 $D$）：
$$\frac{1}{F(D^2)} \sin(\omega x) = \frac{1}{F(-\omega^2)} \sin(\omega x) \quad (F(-\omega^2) \neq 0)$$
- 若分母剩有一阶项 $\frac{1}{aD + b}$，分子分母同乘 $(b - aD)$，分母变为 $b^2 - a^2 D^2 = b^2 + a^2 \omega^2$，分子直接微商！

#### 秘籍 4：多项式展开法（长除法/麦克劳林展开）
对于多项式 $P_m(x)$，将逆算子 $\frac{1}{F(D)}$ 按 $D$ 展开为有限阶多项式 $\frac{1}{1 - u} = 1 + u + u^2 + \dots$，由于高阶微商 $D^{m+1} P_m(x) = 0$，展开到 $D^m$ 项即可直接截断！

## 💡 五、 3 分钟解题肌肉记忆自检清单
1. **看到方程不含 $y$** $\implies$ 令 $y' = p, y'' = p'$，直接化为一阶关于 $x$ 的方程；
2. **看到方程不含 $x$** $\implies$ 令 $y' = p, y'' = p \frac{dp}{dy}$，化为一阶关于 $y$ 的方程；
3. **看到 $y'' + py' + qy = 0$** $\implies$ 写出 $r^2+pr+q=0$，找实根、重根或复根直接套通解模版！
