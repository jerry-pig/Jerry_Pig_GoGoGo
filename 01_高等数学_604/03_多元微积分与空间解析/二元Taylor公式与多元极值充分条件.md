# 二元Taylor公式与多元极值充分条件

> **图谱所属**：[[00_高数知识图谱_MOC]]  
> **考纲定位**：604 高等数学 · 多元微分学极值判定（大纲明确要求）  
> **掌握度**：🟩 能够利用二阶偏导数行列式判定局部极值

---

## 📌 1. 核心定理与极值判定法

### 1. 二元 Taylor 展开（二阶形式）
设 $f(x,y)$ 在点 $(x_0, y_0)$ 的某邻域内具有连续的二阶偏导数，记 $h = x - x_0, k = y - y_0$，则：
$$
f(x_0+h, y_0+k) = f(x_0, y_0) + (h f_x + k f_y) + \frac{1}{2!} (h^2 f_{xx} + 2hk f_{xy} + k^2 f_{yy}) + o(h^2+k^2)
$$
写成矩阵形式：
$$
f(X) = f(X_0) + \nabla f(X_0)^T (X-X_0) + \frac{1}{2} (X-X_0)^T H(X_0) (X-X_0) + o(\|X-X_0\|^2)
$$
其中 $H(X_0)$ 是 **Hessian 矩阵**：
$$
H = \begin{pmatrix}
f_{xx} & f_{xy} \\
f_{yx} & f_{yy}
\end{pmatrix}
$$

### 2. 极值充分条件（判别式法）
设 $(x_0, y_0)$ 是 $f(x,y)$ 的驻点（即 $f_x=0, f_y=0$）。令：
$$
A = f_{xx}(x_0, y_0), \quad B = f_{xy}(x_0, y_0), \quad C = f_{yy}(x_0, y_0)
$$
计算判别式：
$$
\Delta = AC - B^2 = \det(H)
$$
- **若 $\Delta > 0$**：函数在此点有极值。
  - **若 $A > 0$**（Hessian 矩阵正定）：为**极小值**；
  - **若 $A < 0$**（Hessian 矩阵负定）：为**极大值**。
- **若 $\Delta < 0$**（Hessian 矩阵不定）：无极值，此点为**鞍点**。
- **若 $\Delta = 0$**：失效，无法判定（需更高阶展开或几何分析，如 $f(x,y) = x^4+y^4$ 与 $f(x,y) = x^4-y^4$）。

---

## 🧠 2. 费曼白话直觉

- **判别式的物理直观**：在驻点处，一阶切面是平的。极值取决于二阶展开项 $A h^2 + 2B hk + C k^2$。这是一个二次型！
  - 若 $\Delta = AC - B^2 > 0$，说明不管你怎么向外走，函数都是单调向上弯曲（极小值）或单调向下弯曲（极大值）。
  - 若 $\Delta = AC - B^2 < 0$，说明沿着某些方向它是凹的，沿着另一些方向它是凸的，就像马鞍一样（鞍点）。

## 🛠️ 3. 经典母题与推导骨架

### 【母题】
求函数 $f(x,y) = x^3 - y^3 - 3x^2 + 3y^2$ 的极值。

### 【解题骨架】
1. **求一阶偏导找驻点**：
   $$
   \begin{cases}
   f_x = 3x^2 - 6x = 3x(x-2) = 0 \\
   f_y = -3y^2 + 6y = -3y(y-2) = 0
   \end{cases}
   $$
   驻点为：$(0,0), (0,2), (2,0), (2,2)$。
2. **求二阶偏导数**：
   $$
   f_{xx} = 6x-6, \quad f_{xy} = 0, \quad f_{yy} = -6y+6
   $$
3. **逐点分析 $\Delta = f_{xx}f_{yy} - f_{xy}^2$**：
   - 对于 $(0,0)$：$A=-6, B=0, C=6 \implies \Delta = -36 < 0 \implies$ 鞍点，无极值。
   - 对于 $(2,2)$：$A=6, B=0, C=-6 \implies \Delta = -36 < 0 \implies$ 鞍点，无极值。
   - 对于 $(2,0)$：$A=6, B=0, C=6 \implies \Delta = 36 > 0$，且 $A > 0 \implies$ 极小点，极小值为 $f(2,0) = -4$。
   - 对于 $(0,2)$：$A=-6, B=0, C=-6 \implies \Delta = 36 > 0$，且 $A < 0 \implies$ 极大点，极大值为 $f(0,2) = 4$。

## 🕳️ 4. 避坑手记
- **混合偏导对称性**：必须在二阶偏导连续的前提下才有 $f_{xy} = f_{yx}$。
- **$\Delta$ 的正负号记忆**：千万别把公式记成 $B^2 - AC$。如果记成了 $B^2-AC$，极值的条件就变成了该值小于 0，极易与一元二次方程的判别式混淆而写错符号。记住 $\Delta = \det(H) = AC - B^2$。
