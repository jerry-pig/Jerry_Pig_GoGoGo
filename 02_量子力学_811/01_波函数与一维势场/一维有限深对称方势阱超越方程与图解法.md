## 💡 0. 费曼直觉：有限深 vs 无限深（看懂这三句话，彻底通透！）

> [!TIP]
> ### 🌟 核心物理直觉：
> 1. **波函数溢出效应（吉他弦穿入海绵）**：  
>    - 在**无限深方势阱**中，墙是无限坚硬的，波函数在边界 $x = \pm a$ 处被硬生生压成 0，一点都透不出去。  
>    - 在**有限深方势阱**中，墙的高度有限（$V_0$）。波函数**不会在边界突然中断，而是会“渗透溢出”到势阱外，并在外部呈指数衰减（$e^{-\kappa |x|}$）**。
> 2. **为什么有限深势阱的能级更低？**  
>    因为波函数往外“渗”出去了一小段，相当于有效波长 $\lambda$ 变长了！根据德布罗意关系 $p = \frac{h}{\lambda}$，动量变小了，因此**有限深势阱的每一个能级，都比无限深势阱对应的能级要低一截**！
> 3. **至少存在一个束缚态的铁律**：  
>    在一维空间中，由于没有三维空间的离心势垒阻碍，**不管一维对称有限深势阱多么浅、多么窄（哪怕 $V_0 \to 0$），体系永远都至少存在 1 个偶宇称束缚态（基态）！**

## 🧭 一、 物理模型与定态薛定谔方程

考虑对称矩形有限深势阱（阱深 $V_0 > 0$，阱宽 $2a$）：
$$V(x) = \begin{cases} 0, & |x| \le a \quad \text{(阱内区域 I)} \\ V_0, & |x| > a \quad \text{(阱外区域 II)} \end{cases}$$

研究束缚态：**$0 < E < V_0$**。

引入实数参量（阱内波数 $k$ 与阱外衰减常数 $\kappa$）：
$$k = \frac{\sqrt{2mE}}{\hbar} > 0, \quad \kappa = \frac{\sqrt{2m(V_0 - E)}}{\hbar} > 0$$

### 空间反演对称性与宇称分类：
因为势场具有中心对称性 $V(-x) = V(x)$，哈密顿量与宇称算符对易 $[H, \hat{P}] = 0$，所以定态波函数必然具有确定的宇称（偶宇称或奇宇称）：

| 分类 | 阱内波函数 ($|x| \le a$) | 阱外波函数 ($|x| > a$) |
| :---: | :---: | :---: |
| **偶宇称 (Even Parity)** | $\psi(x) = A \cos(kx)$ | $\psi(x) = C e^{-\kappa |x|}$ |
| **奇宇称 (Odd Parity)** | $\psi(x) = B \sin(kx)$ | $\psi(x) = \text{sgn}(x) D e^{-\kappa |x|}$ |

## 🔬 二、 边界连续性与无量纲超越方程

在边界 $x = a$ 处，波函数本身及其一阶导数必须连续（$\psi(a^-) = \psi(a^+), \psi'(a^-) = \psi'(a^+)$）：

### 1. 偶宇称态边界匹配：
$$\begin{cases} A \cos(ka) = C e^{-\kappa a} \\ -k A \sin(ka) = -\kappa C e^{-\kappa a} \end{cases} \implies \frac{k A \sin(ka)}{A \cos(ka)} = \frac{\kappa C e^{-\kappa a}}{C e^{-\kappa a}} \implies k \tan(ka) = \kappa$$

### 2. 奇宇称态边界匹配：
$$\begin{cases} B \sin(ka) = D e^{-\kappa a} \\ k B \cos(ka) = -\kappa D e^{-\kappa a} \end{cases} \implies \frac{k B \cos(ka)}{B \sin(ka)} = \frac{-\kappa D e^{-\kappa a}}{D e^{-\kappa a}} \implies -k \cot(ka) = \kappa$$

## 🎨 三、 几何画圆图解法（0 繁琐代数，一眼看穿能级个数！）

为了彻底摆脱抽象的代数，我们引入两个**无量纲变量**：
$$\xi = ka \ge 0, \quad \eta = \kappa a \ge 0$$

### 1. 毕达哥拉斯结构圆方程：
$$\xi^2 + \eta^2 = (ka)^2 + (\kappa a)^2 = \frac{2mE}{\hbar^2}a^2 + \frac{2m(V_0 - E)}{\hbar^2}a^2 = \frac{2m V_0 a^2}{\hbar^2} \equiv R^2$$
这是一个以原点为圆心、**半径为 $R = \frac{\sqrt{2mV_0}a}{\hbar}$** 的圆！  
*(圆半径 $R$ 完全由势阱的内在物理参数——“阱深 $V_0 \times$ 阱宽 $a^2$”唯一决定！)*

### 2. 超越方程的无量纲曲线：
- **偶宇称曲线**：$\eta = \xi \tan \xi$
- **奇宇称曲线**：$\eta = -\xi \cot \xi$

```
  η (阱外衰减)
  ▲
  │   偶(1)    奇(1)    偶(2)    奇(2)
  │   │ /      │ \      │ /      │ \
  │   │/       │  \     │/       │  \
  │  /│        │   \   /│        │   \
  │ / │        │    \ / │        │    \
  │/  │        │     X  │        │     \
  ┼───┼────────┼─────┼──┼────────┼──────► ξ (阱内动量)
  0   π/2      π    3π/2 2π     5π/2
```

### 3. 三大秒杀考点（考场直接写出结论！）：

1. **为什么永远至少有 1 个偶宇称束缚态？**  
   因为偶宇称曲线 $\eta = \xi \tan \xi$ 是从**坐标原点 $(0,0)$ 出发**向上翘的曲线。第一象限内任何半径 $R > 0$ 的圆弧，**必定会与该曲线在 $(0, \pi/2)$ 区间内有且仅有 1 个交点**！  
   $\implies$ **一维对称有限深方势阱无论多浅，至少存在 1 个束缚态（基态必为偶宇称）！**
2. **出现奇宇称态的临界深度条件**：  
   奇宇称曲线 $\eta = -\xi \cot \xi$ 是在 $\xi = \frac{\pi}{2}$ 处才从横轴冒出来的。  
   因此，圆半径必须满足 **$R > \frac{\pi}{2}$** 时，圆弧才会与奇宇称曲线产生交点！  
   $$\text{存在奇宇称态的条件} \iff R = \frac{\sqrt{2mV_0}a}{\hbar} > \frac{\pi}{2} \iff V_0 a^2 > \frac{\pi^2 \hbar^2}{8m}$$
3. **束缚态总数极速判定口诀**：  
   考察无量纲半径 $R$ 跨过了几个 $\frac{\pi}{2}$ 的分界线：
   若 $n \frac{\pi}{2} < R \le (n+1)\frac{\pi}{2}$，则体系共有 **$n + 1$ 个束缚态**（偶奇偶奇交替排列）！

## 🎯 四、 典型国科大 811 真题母题演练

### 【经典考题】
已知电子质量为 $m$，在一维对称有限深方势阱中运动，阱宽 $2a = 1\,\text{nm}$。若已知该势阱中**恰好存在 3 个束缚态**，求势阱深度 $V_0$ 的取值范围。

### 【秒杀推导只需 3 步】：
1. **写出束缚态数目判据**：  
   恰好有 3 个束缚态（2个偶宇称 + 1个奇宇称） $\implies$ 半径 $R$ 必须满足：
   $$\pi < R \le \frac{3\pi}{2}$$
2. **代入半径定义 $R = \frac{\sqrt{2mV_0}a}{\hbar}$**：
   $$\pi < \frac{\sqrt{2mV_0}a}{\hbar} \le \frac{3\pi}{2}$$
3. **两边平方解出 $V_0$ 范围**：
   $$\frac{\pi^2 \hbar^2}{2m a^2} < V_0 \le \frac{9\pi^2 \hbar^2}{8m a^2}$$
   *(推导耗时不到 3 分钟，满分 15 分直接到手！)*

## ⚠️ 五、 避坑手记（Exam Traps）

1. **阱宽是 $2a$ 不是 $a$**：题目给出的阱宽如果是 $2a$，半宽度才是 $a$。计算半径 $R$ 时一定要用半宽度 $a$，切勿把全宽当半宽代入！
2. **基态宇称绝不为奇**：由于节点定理，基态没有节点，因此基态永远是偶宇称态 $\cos(kx)$，第一激发态才是奇宇称态 $\sin(kx)$。
3. **趋于无限深势阱的极限定检**：当 $V_0 \to \infty$ 时，$R \to \infty$，交点被推至 $\xi = ka = n \frac{\pi}{2}$，即 $k(2a) = n\pi$，完全自然退化为无限深势阱的本征解 $E_n = \frac{n^2 \pi^2 \hbar^2}{2m(2a)^2}$！
