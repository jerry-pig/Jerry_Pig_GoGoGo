## 🌌 1. 物理模型与哈密顿量（周期边界）

粒子被限制在半径为 $R$（或周长 $L=2\pi R$）的**刚性圆环**上自由运动，沿圆周的角坐标为 $\varphi \in [0, 2\pi)$：
$$
\hat{H} = -\frac{\hbar^2}{2mR^2} \frac{d^2}{d\varphi^2}
$$

### ⚠️ 与普通方势阱的根本区别（致命踩坑点）

| | 一维无限深方势阱（硬壁） | 圆环（周期边界） |
| :--- | :--- | :--- |
| 边界条件 | $\psi(0) = \psi(a) = 0$（Dirichlet） | $\psi(\varphi + 2\pi) = \psi(\varphi)$（周期性） |
| 波函数 | $\sin(n\pi x/a)$ | $e^{in\varphi}$ |
| 量子数 | $n = 1, 2, 3, \dots$ | $n = 0, \pm 1, \pm 2, \dots$ |
| 简并度 | **无简并**（$n$ 唯一确定） | **二重简并**（$\pm n$ 同能） |
| 能量 | $E_n = \frac{n^2\pi^2\hbar^2}{2mL^2}$ | $E_n = \frac{n^2\hbar^2}{2mR^2}$，$n\neq 0$ 时二重简并 |

## ⚡ 2. 本征解与能级（完整推导）

解方程 $\frac{d^2\psi}{d\varphi^2} = -k^2\psi$，通解为：
$$
\psi(\varphi) = Ae^{in\varphi}
$$

代入周期边界条件 $\psi(\varphi + 2\pi) = \psi(\varphi)$：
$$
e^{in(\varphi + 2\pi)} = e^{in\varphi} \implies e^{i 2\pi n} = 1 \implies n \in \mathbb{Z}
$$

归一化（$\int_0^{2\pi}|\psi|^2 R\,d\varphi = 1$，或简化为 $\int_0^{2\pi}|\psi|^2 d\varphi = 1$）：
$$
\psi_n(\varphi) = \frac{1}{\sqrt{2\pi}} e^{in\varphi}, \quad n = 0, \pm1, \pm2, \dots
$$

能谱：
$$
E_n = \frac{n^2\hbar^2}{2mR^2}
$$
- **基态** $n=0$：非简并，$E_0 = 0$
- **激发态** $n = \pm 1, \pm 2, \dots$：**二重简并**，$E_n = E_{-n}$

## 🛠️ 3. 高频考题变形处理

### 变形 1（2016年真题）：$t=0$ 时给定 $\Psi = A\sin^2\varphi$，求 $t$ 时刻波函数
1. 利用三角恒等式展开：$\sin^2\varphi = \frac{1-\cos 2\varphi}{2} = \frac{1}{2} - \frac{1}{4}e^{2i\varphi} - \frac{1}{4}e^{-2i\varphi}$
2. 对照本征态展开，识别系数 $c_n$；
3. 加上时间因子：$\Psi(\varphi, t) = \sum_n c_n\psi_n(\varphi)e^{-iE_n t/\hbar}$。

### 变形 2（2022年真题）：引入微扰 $H' = \lambda\cos(2\varphi)$
1. 微扰矩阵元：$\langle n'|H'|n\rangle = \frac{\lambda}{2\pi}\int_0^{2\pi}e^{-in'\varphi}\cos(2\varphi)e^{in\varphi}d\varphi$；
2. 利用 $\cos(2\varphi) = \frac{1}{2}(e^{2i\varphi}+e^{-2i\varphi})$ 计算，只有 $n'-n = \pm 2$ 时矩阵元非零；
3. 注意 $n = \pm 1$ 态为**简并态**，需用简并微扰论（久期行列式）！
