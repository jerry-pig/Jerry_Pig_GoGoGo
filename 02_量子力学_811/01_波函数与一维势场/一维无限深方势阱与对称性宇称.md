## 📌 一、 核心物理模型与坐标系对比

一维无限深方势阱在 811 考研中有两种典型坐标设定，二者本质是平移关系：

| 指标 | 设定 A：非对称势阱 $[0, a]$ | 设定 B：中心对称势阱 $[-a, a]$ (811 核心) |
| :--- | :---: | :---: |
| **势阱定义** | $V=0 \ (0<x<a)$，其余处 $V=+\infty$ | $V=0 \ (|x|<a)$，其余处 $V=+\infty$ |
| **势阱总宽度 $L$** | $L = a$ | $L = 2a$ |
| **势场对称性** | 无对称性（原点在左壁） | 空间反演对称：$V(-x) = V(x)$ |
| **波函数形式** | 全部为正弦函数 $\sin\left(\frac{n\pi x}{a}\right)$ | 奇偶交替：偶态 $\cos\left(\frac{n\pi x}{2a}\right)$ 与 奇态 $\sin\left(\frac{n\pi x}{2a}\right)$ |
| **能级公式** | $E_n = \frac{n^2 \pi^2 \hbar^2}{2m a^2}$ | $E_n = \frac{n^2 \pi^2 \hbar^2}{2m (2a)^2} = \mathbf{\frac{n^2 \pi^2 \hbar^2}{8m a^2}}$ |

## 🔬 二、 对称模型 $[-a, a]$ 的严格解法与归一化

### 1. 薛定谔方程与通解
在势阱内部（$|x| < a$），势能 $V = 0$：
$$-\frac{\hbar^2}{2m} \frac{d^2\psi}{dx^2} = E\psi \implies \frac{d^2\psi}{dx^2} + k^2\psi = 0, \quad k = \frac{\sqrt{2mE}}{\hbar}$$

### 2. 宇称分类求解
因为势场满足 $V(-x) = V(x)$，哈密顿量与宇称算符对易 $[H, \hat{P}] = 0$。一维束缚态无简并，波函数必须具有确定的宇称：

#### ① 偶宇称解（基态 $n=1$、第二激发态 $n=3\dots$）
设 $\psi(x) = C \cos(kx)$。代入边界条件 $\psi(a) = 0$：
$$\cos(ka) = 0 \implies ka = \frac{n\pi}{2} \quad (n = 1, 3, 5, \dots)$$

**归一化严格手算（绝无含糊）**：
$$\int_{-a}^{a} C^2 \cos^2(kx) dx = C^2 \int_{-a}^{a} \frac{1 + \cos(2kx)}{2} dx = 1$$
- 第一项：$\int_{-a}^a \frac{1}{2} dx = a$；
- 第二项求原函数严格代入：
  $$\left[ \frac{1}{4k} \sin(2kx) \right]_{-a}^{a} = \frac{1}{4k} \Big( \sin(2ka) - \sin(-2ka) \Big)$$
  由于 $2ka = n\pi$（$n$ 为奇数），$\sin(n\pi) = 0$，严格为 $0 - 0 = 0$！
- 故 $C^2 \cdot a = 1 \implies \mathbf{C = \frac{1}{\sqrt{a}}}$。

#### ② 奇宇称解（第一激发态 $n=2$、第三激发态 $n=4\dots$）
设 $\psi(x) = D \sin(kx)$。代入边界条件 $\psi(a) = 0$：
$$\sin(ka) = 0 \implies ka = \frac{n\pi}{2} \quad (n = 2, 4, 6, \dots)$$
同样严格手算得：$\mathbf{D = \frac{1}{\sqrt{a}}}$。

## 📐 三、 节点定理（Node Theorem）

> **节点定义**：波函数在势阱内部开区间 $(-a, a)$ 内**穿过零点的个数**（边界 $\pm a$ 不算节点）。

- **定理**：第 $n$ 个能量本征态 $\psi_n(x)$ 严格具有 **$n - 1$ 个节点**！
  - $n=1$（基态）：$0$ 个节点，在开区间内恒为正（余弦波峰），绝不触碰零轴；
  - $n=2$（第一激发态）：$1$ 个节点，恰好在对称中心 $x=0$ 处穿过零点；
  - $n=3$（第二激发态）：$2$ 个节点，在 $x = \pm \frac{2}{3}a$ 处穿过零点。
- **物理直觉**：节点越多 $\implies$ 波函数弯曲越剧烈 $\implies$ 二阶导数越大 $\implies$ 粒子动能与总能量越高！

## ⚡ 四、 经典力学量期望值计算（代数与物理双重解析）

### 1. 坐标期望值 $\langle x \rangle = 0$
$$\langle x \rangle = \int_{-a}^{a} x |\psi_n(x)|^2 dx = 0$$
- **严格代数证明**：无论波函数本身是奇是偶，其概率密度 $|\psi_n(x)|^2$ 必为**偶函数**。被积函数 $x |\psi_n|^2$ 是（奇 $\times$ 偶）= **奇函数**，在对称区间 $[-a, a]$ 上积分必为零！

### 2. 动量期望值 $\langle p \rangle = 0$

#### ① 严格代数证明（导数奇偶性）：
$$\langle p \rangle = \int_{-a}^{a} \psi_n^*(x) \left(-i\hbar \frac{d}{dx}\right) \psi_n(x) dx = -i\hbar \int_{-a}^{a} \psi_n(x) \frac{d\psi_n}{dx} dx$$
- 若 $\psi_n$ 是**偶函数**（余弦），则导数 $\frac{d\psi_n}{dx}$ 必为**奇函数**，乘积 $\psi_n \frac{d\psi_n}{dx}$ 为**奇函数**，对称区间积分严格为 0！
- 若 $\psi_n$ 是**奇函数**（正弦），则导数 $\frac{d\psi_n}{dx}$ 必为**偶函数**，乘积 $\psi_n \frac{d\psi_n}{dx}$ 仍为**奇函数**，对称区间积分严格为 0！
- **利用全微分直接积出**：
  $$\int_{-a}^{a} \psi_n \frac{d\psi_n}{dx} dx = \frac{1}{2} \int_{-a}^a \frac{d}{dx}[\psi_n^2] dx = \frac{1}{2} \Big[ \psi_n^2(a) - \psi_n^2(-a) \Big] = \frac{1}{2}(0 - 0) = 0$$

#### ② 物理直觉：欧拉公式看穿“驻波抵消”
用欧拉公式把三角波拆开：
$$\cos(kx) = \frac{1}{2} \mathbf{e^{ikx}} + \frac{1}{2} \mathbf{e^{-ikx}}$$
- $e^{ikx}$ 是动量为 **$+ \hbar k$**（向右跑）的行波；
- $e^{-ikx}$ 是动量为 **$- \hbar k$**（向左跑）的行波；
- 两者的振幅权重完全相等（各占 50% 概率）。
- **物理本质**：粒子在两个硬墙之间来回反弹形成了定态驻波，向右运动的几率与向左运动的几率严格各占一半，平均净动量必定为零！

## 🕳️ 五、 考场避坑手记

1. **分母是 $8ma^2$ 还是 $2ma^2$**：
   - 看到题目势阱范围是 $[-a, a]$ 时，阱宽是 $2a$，分母算式是 $2m(2a)^2 = 8ma^2$！
   - 看到题目势阱范围是 $[0, a]$ 时，阱宽是 $a$，分母才是 $2ma^2$！
2. **基态开口方向的全局相位**：
   $\psi_1(x) = \frac{1}{\sqrt{a}}\cos(\frac{\pi x}{2a})$ 与 $-\frac{1}{\sqrt{a}}\cos(\frac{\pi x}{2a})$ 在物理上完全等价（几率密度与力学量期望值完全相同），约定俗成取正值。
