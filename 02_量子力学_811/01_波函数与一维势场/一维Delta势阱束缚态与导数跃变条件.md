## 🧭 一、 物理情景与哈密顿量

设一维质量为 $m$ 的粒子在单吸引型 $\delta$ 势阱中运动：
$$V(x) = -\alpha \delta(x) \quad (\alpha > 0)$$

定态薛定谔方程为：
$$-\frac{\hbar^2}{2m}\frac{d^2\psi(x)}{dx^2} - \alpha \delta(x)\psi(x) = E\psi(x)$$

---

## 🔬 二、 核心断点 1：波函数在奇点处的导数跃变条件推导

当势能包含 Dirac $\delta$ 函数时，势场在 $x=0$ 处无限深发散，此时波函数**本身保持连续**，但其**一阶导数产生有限阶跃**！

### 严格积分推导：
在开区间 $[-\epsilon, +\epsilon]$ 上对定态薛定谔方程两边积分：
$$-\frac{\hbar^2}{2m}\int_{-\epsilon}^{+\epsilon} \psi''(x)\,dx - \alpha \int_{-\epsilon}^{+\epsilon} \delta(x)\psi(x)\,dx = E \int_{-\epsilon}^{+\epsilon} \psi(x)\,dx$$

令 $\epsilon \to 0^+$ 取极限：
1. 第一项：$-\frac{\hbar^2}{2m} [\psi'(0^+) - \psi'(0^-)]$；
2. 第二项：$-\alpha \psi(0)$（利用 $\delta$ 函数的筛选性质）；
3. 右边项：$\lim_{\epsilon \to 0} E \int_{-\epsilon}^{+\epsilon} \psi(x)\,dx = 0$（因为 $\psi(x)$ 有限连续，积分区间长度趋于零）。

由此严格导出**一维 $\delta$ 势场的导数跃变匹配条件**：
$$\Delta \psi'(0) = \psi'(0^+) - \psi'(0^-) = -\frac{2m\alpha}{\hbar^2}\psi(0)$$

## 🎯 三、 核心断点 2：束缚态 ($E < 0$) 能量本征值与波函数求解

设束缚态能量 $E = -|E| < 0$，引入衰减波数：
$$\kappa = \frac{\sqrt{2m|E|}}{\hbar} > 0 \implies E = -\frac{\hbar^2\kappa^2}{2m}$$

### 1. 区域波函数解
在 $x \neq 0$ 区域，$V(x) = 0$，薛定谔方程化为 $\psi''(x) = \kappa^2 \psi(x)$：
- 当 $x > 0$ 时，满足 $x\to+\infty$ 波函数平方可积（有界）：$\psi_R(x) = A e^{-\kappa x}$；
- 当 $x < 0$ 时，满足 $x\to-\infty$ 波函数平方可积（有界）：$\psi_L(x) = B e^{\kappa x}$。

### 2. 边界匹配与本征值
- **在 $x=0$ 处波函数连续**：$\psi(0^-) = \psi(0^+) \implies B = A$。  
  波函数写为统一形式：$\psi(x) = A e^{-\kappa |x|}$（偶宇称态）。
- **在 $x=0$ 处代入导数跃变条件**：
  $$\psi'(0^+) = -\kappa A, \quad \psi'(0^-) = \kappa A$$
  代入匹配式：
  $$(-\kappa A) - (\kappa A) = -\frac{2m\alpha}{\hbar^2} A \implies -2\kappa A = -\frac{2m\alpha}{\hbar^2} A$$
  由于束缚态非平凡解 $A \neq 0$，立刻解得衰减波数：
  $$\kappa = \frac{m\alpha}{\hbar^2}$$

### 3. 束缚态能级与归一化波函数
- **能量本征值**：
  $$E_0 = -\frac{\hbar^2\kappa^2}{2m} = -\frac{\hbar^2}{2m}\left(\frac{m\alpha}{\hbar^2}\right)^2 = -\frac{m\alpha^2}{2\hbar^2}$$
- **波函数归一化**：
  $$\int_{-\infty}^{+\infty} |\psi(x)|^2\,dx = 2 \int_0^\infty A^2 e^{-2\kappa x}\,dx = 2A^2 \cdot \frac{1}{2\kappa} = \frac{A^2}{\kappa} = 1 \implies A = \sqrt{\kappa} = \frac{\sqrt{m\alpha}}{\hbar}$$
  因此归一化基态波函数为：
  $$\psi_0(x) = \sqrt{\frac{m\alpha}{\hbar^2}}\,e^{-\frac{m\alpha}{\hbar^2}|x|}$$

## ❓ 四、 为什么一维 $\delta$ 势阱只有唯一个束缚态？（奇偶宇称与节点定理）

### 1. 节点定理（Node Theorem / Sturm-Liouville 理论）
- **基态（$n=0$）**：有限空间内**无节点**，波函数恒不穿过零点变号；
- **第一激发态（$n=1$）**：恰有 **1 个节点**；
- **第 $n$ 激发态**：恰有 **$n$ 个节点**。

### 2. 奇宇称激发态的毁灭论证（为什么无解）：
1. 势场具有反演对称性 $V(-x)=V(x)$，故定态必须具有确定的宇称；
2. 如果存在第一激发态，它必须具备 1 个节点。对称中心在 $x=0$，故**该唯一的节点必须落在原点**，即：
   $$\psi(0) = 0$$
3. 将 $\psi(0) = 0$ 代入导数跃变匹配条件：
   $$\psi'(0^+) - \psi'(0^-) = -\frac{2m\alpha}{\hbar^2}\psi(0) = 0 \implies \psi'(0^+) = \psi'(0^-)$$
4. **零解坍塌**：在原点处，波函数既为零（$\psi(0)=0$），一阶导数又连续（$\psi'(0^+)=\psi'(0^-)$）。对于指数衰减分段解 $\psi(x) = C \operatorname{sgn}(x) e^{-\kappa|x|}$，要同时满足连续与光滑，系数必须满足 $C = -C \implies C = 0$。
5. **结论**：微分方程退化为全空间处处为零的平凡零解。因此一维单 $\delta$ 势阱**无论势阱参数 $\alpha$ 多大，永远仅有唯一一个偶宇称束缚态**！

## 🎸 五、 吉他弦模型与宇称交替 / 正交性深度剖析

```
能级       宇称      节点数   空间形状直觉 (吉他弦图像)             与基态正交机制
──────────────────────────────────────────────────────────────────────────────────
基态 E₀    偶宇称    0 节点   整根弦整体向上凸起 (大肚子)          归一化基底
激发态 E₁  奇宇称    1 节点   左凹右凸，原点不动 (反对称)          奇偶函数相乘积分为零
激发态 E₂  偶宇称    2 节点   两边上凸，中间下凹 (对称振荡)        两偶函数相乘正负面积相消
```

### 1. 为什么不同能级必须正交？
哈密顿量 $\hat{H}$ 是厄米算符。由线性代数基本定理，**属于不同能量本征值的态天然严格正交**：
$$\int_{-\infty}^{+\infty} \psi_m^*(x)\psi_n(x)\,dx = 0 \quad (E_m \neq E_n)$$
物理上代表它们是互不干扰、永不串扰的独立量子态通道。

### 2. 两个偶函数如何实现全空间正交？（解决 Jerry 的追问）
- 很多初学者误以为“偶函数乘偶函数必为偶函数，在对称区间积分必大于零”；
- **误区突破**：偶函数乘偶函数确实还是偶函数，但偶函数**可以变号（有正有负）**！
- $\psi_2(x)$ 在原点附近是负值，在外侧是正值。当计算 $\int_{-\infty}^\infty \psi_0(x)\psi_2(x)dx$ 时，原点附近的负面积与两侧的正面积**绝对值精确相等，抵消为零**！

## 🌊 六、 几率流密度与定态实波函数定理

几率流密度定义为：
$$J(x) = \frac{\hbar}{2mi}\left(\psi^* \frac{d\psi}{dx} - \psi \frac{d\psi^*}{dx}\right) = \frac{\hbar}{m}\operatorname{Im}\left(\psi^* \frac{d\psi}{dx}\right)$$

- **计算上述束缚态的几率流密度**：
  由于 $\psi_0(x) = \sqrt{\kappa}e^{-\kappa |x|}$ 是纯实数函数，$\psi_0^* = \psi_0$。
  $$J(x) = \frac{\hbar}{2mi}\left(\psi_0 \psi_0' - \psi_0 \psi_0'\right) \equiv 0$$
- **普遍物理定理**：
  **任意一维定态束缚态（或无简并定态）的波函数总可以通过提取全局相位化为纯实数，其实波函数的几率流密度在全空间恒等于零（$J \equiv 0$）**。
  - 物理图像：束缚态对应**驻波**，没有净概率流向无穷远处定向传输，几率在空间处于静止稳定分布（满足连续性方程 $\frac{\partial \rho}{\partial t} = -\frac{\partial J}{\partial x} = 0$）。

## ⚠️ 七、 避坑手记与高分要诀

1. **不可直接求二阶导**：在 $x=0$ 处切忌直接求导（会产生 $\delta'(x)$ 奇异项导致推导崩溃），必须严格走“微小区间积分 $\to$ 导数跃度”路径。
2. **负号与系数**：跃变式右侧含有 $-\frac{2m\alpha}{\hbar^2}\psi(0)$，求衰减常数时注意左右导数相减的方向：$\psi'(0^+) - \psi'(0^-) = -\kappa A - \kappa A = -2\kappa A$。
3. **解释唯一性时的踩分点**：一定要写出**节点定理 + 奇宇称在原点过零 + 导数无跃变导致全空间零解坍塌**这三句话，阅卷老师一眼给满分！
