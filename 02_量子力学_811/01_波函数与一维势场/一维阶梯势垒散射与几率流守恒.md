## 一、 核心物理模型

* **势场分布**：$V(x) = \begin{cases} 0, & x < 0 \quad (\text{区域 I}) \\ V_0, & x > 0 \quad (\text{区域 II}) \end{cases}$，粒子能量 $E > V_0$。
* **波函数行波法设定**：
  * 区域 I ($x<0$): $\psi_I(x) = e^{ik_1 x} + R' e^{-ik_1 x}$ （包含振幅为 1 的入射波和振幅为 $R'$ 的反射波）
  * 区域 II ($x>0$): $\psi_{II}(x) = T' e^{ik_2 x}$ （仅包含振幅为 $T'$ 的透射波，右侧无反射源）
* **波数定义**：
  * $k_1 = \frac{\sqrt{2mE}}{\hbar}$
  * $k_2 = \frac{\sqrt{2m(E-V_0)}}{\hbar}$

---

## 二、 核心推导步骤骨架

1. **边界条件匹配**：
   * 连续性条件 $\psi_I(0) = \psi_{II}(0) \implies 1 + R' = T'$
   * 一阶导数连续 $\psi_I'(0) = \psi_{II}'(0) \implies ik_1(1 - R') = ik_2 T'$
2. **振幅求解**：
   * 反射振幅：$R' = \frac{k_1 - k_2}{k_1 + k_2}$
   * 透射振幅：$T' = \frac{2k_1}{k_1 + k_2}$
3. **几率流密度与系数转换**：
   * 几率流密度定义：$J = \frac{\hbar}{2mi} \left( \psi^* \frac{\partial \psi}{\partial x} - \psi \frac{\partial \psi^*}{\partial x} \right) = \frac{\hbar k}{m} |\psi|^2$
   * 反射系数：$R = \frac{J_{\text{ref}}}{J_{\text{inc}}} = |R'|^2 = \left(\frac{k_1 - k_2}{k_1 + k_2}\right)^2$
   * 透射系数（**含速度/波数修正**）：$T = \frac{J_{\text{trans}}}{J_{\text{inc}}} = \frac{k_2}{k_1} |T'|^2 = \frac{k_2}{k_1} \frac{4k_1^2}{(k_1 + k_2)^2} = \frac{4k_1 k_2}{(k_1 + k_2)^2}$
4. **几率流守恒验证**：
   * $R + T = \frac{(k_1 - k_2)^2 + 4k_1 k_2}{(k_1 + k_2)^2} = \frac{(k_1 + k_2)^2}{(k_1 + k_2)^2} = 1$

---

## 三、 易错踩坑清单（Warning）

* **陷阱 1（波函数多余项）**：区域 II 因为没有来自右侧的反射或入射源，切勿多写 $B e^{-ik_2 x}$ 终态项。
* **陷阱 2（透射系数漏乘速度比）**：计算透射系数 $T$ 时，**绝不能直接等于 $|T'|^2$**，必须乘以两区域的几率流密度比（即波数比 $\frac{k_2}{k_1}$），因为势垒改变了粒子的传播速度！
* **陷阱 3（能量条件审题）**：本题限定 $E > V_0$（高能贯穿）；若考题变为 $E < V_0$（全反射），波数 $k_2$ 将变为纯虚数 $i\kappa$，波函数转为衰减的指数函数，反射系数 $R = 1$ 但右侧有非零穿透深度！
