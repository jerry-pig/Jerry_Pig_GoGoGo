## 💡 0. 费曼物理直觉与核心图像 (Intuition & Physics)

> [!TIP]
> ### 🌟 量子隧道效应的物理本质：
> 1. **经典物理 vs 量子物理**：  
>    在经典力学中，当粒子总能量 $E < V_0$ 时，粒子撞到势垒会被 100% 弹回（反射系数 $R=1, T=0$），绝对不可能穿入势垒内部。  
>    在量子力学中，粒子以“物质波”形式存在。当波穿入势垒内部（$0 < x < a$）时，波矢量变为虚数 $k \to i\kappa$，波并不立即中断，而是以**实指数形式衰减（隐失波）**。若势垒宽度 $a$ 有限，波穿出右侧时仍有非零振幅，从而产生**穿透概率 $T > 0$**！
> 2. **几率流守恒定理**：  
>    对于定态散射问题，全空间满足几率守恒：入射流 = 反射流 + 透射流，即：
>    $$R + T = 1$$
> 3. **宽势垒的 Gamow 指数衰减律**：  
>    当势垒较厚且高时（$\kappa a \gg 1$），穿透率主要由指数因子决定：$T \propto e^{-2\kappa a}$，这是解释核物理 $\alpha$ 衰变与扫描隧道显微镜 (STM) 的底层原理！

## 🧭 一、 物理情景与分段定态薛定谔方程

设质量为 $m$ 的粒子自左向右入射一维矩形方势垒：
$$V(x) = \begin{cases} 0, & x < 0 \quad \text{(区域 I)} \\ V_0, & 0 \le x \le a \quad \text{(区域 II)} \\ 0, & x > a \quad \text{(区域 III)} \end{cases}$$

考虑低能入射情形：**$0 < E < V_0$（经典禁戒隧道效应）**。

引入实数波数与衰减常数：
$$k = \frac{\sqrt{2mE}}{\hbar} > 0, \quad \kappa = \frac{\sqrt{2m(V_0 - E)}}{\hbar} > 0$$

### 各区域波函数通解：
- **区域 I ($x < 0$, $V=0$)**：入射平面波 + 向左反射波
  $$\psi_I(x) = e^{ikx} + R' e^{-ikx}$$
- **区域 II ($0 \le x \le a$, $V=V_0$)**：势垒内指数衰减波 + 界面反射衰减波
  $$\psi_{II}(x) = C e^{-\kappa x} + D e^{\kappa x}$$
- **区域 III ($x > a$, $V=0$)**：向右透射平面波（右侧无反射源，无向左传播项）
  $$\psi_{III}(x) = T' e^{ikx}$$

## 🔬 二、 边界连续性条件联立求解

波函数在势垒两个跳跃边界 $x = 0$ 和 $x = a$ 处，其**本身及一阶导数必须连续**：

### 1. 在 $x = 0$ 处的匹配方程：
$$\begin{cases} \psi_I(0) = \psi_{II}(0) \implies 1 + R' = C + D \\ \psi_I'(0) = \psi_{II}'(0) \implies ik(1 - R') = -\kappa C + \kappa D \end{cases}$$

### 2. 在 $x = a$ 处的匹配方程：
$$\begin{cases} \psi_{II}(a) = \psi_{III}(a) \implies C e^{-\kappa a} + D e^{\kappa a} = T' e^{ika} \\ \psi_{II}'(a) = \psi_{III}'(a) \implies -\kappa C e^{-\kappa a} + \kappa D e^{\kappa a} = ik T' e^{ika} \end{cases}$$

## 🎯 三、 透射系数 $T$ 与反射系数 $R$ 的严格解析解

### 1. 几率流密度比值定义
- 入射几率流：$J_{\text{inc}} = \frac{\hbar k}{m} |1|^2 = \frac{\hbar k}{m}$；
- 反射几率流：$J_{\text{ref}} = \frac{\hbar k}{m} |R'|^2$；
- 透射几率流：$J_{\text{trans}} = \frac{\hbar k}{m} |T'|^2$。

因此定义：
$$R = \frac{J_{\text{ref}}}{J_{\text{inc}}} = |R'|^2, \quad T = \frac{J_{\text{trans}}}{J_{\text{inc}}} = |T'|^2$$

### 2. 透射系数严格闭式解（双曲正弦形式）
通过矩阵消元解出 $T'$，取模平方后可得国科大 811 标志性解析式：
$$T = \frac{1}{1 + \dfrac{V_0^2}{4E(V_0 - E)} \sinh^2(\kappa a)}$$

相应的反射系数为：
$$R = 1 - T = \frac{\dfrac{V_0^2}{4E(V_0 - E)} \sinh^2(\kappa a)}{1 + \dfrac{V_0^2}{4E(V_0 - E)} \sinh^2(\kappa a)}$$

### 3. 强衰减极限定似（$\kappa a \gg 1$，厚势垒或高势垒）
当 $\kappa a \gg 1$ 时，$\sinh(\kappa a) = \frac{e^{\kappa a} - e^{-\kappa a}}{2} \approx \frac{1}{2}e^{\kappa a}$：
$$\sinh^2(\kappa a) \approx \frac{1}{4}e^{2\kappa a} \gg 1$$
代入分母求倒数，可得**指数衰减极限公式**：
$$T \approx \frac{16E(V_0 - E)}{V_0^2} e^{-2\kappa a}$$

## 🌊 四、 进阶考点：高能入射 ($E > V_0$) 与共振透射现象

若入射能量超过势垒高度 $E > V_0$：
- 衰减常数变为实数波矢：$\kappa \to -ik_2$，其中 $k_2 = \frac{\sqrt{2m(E - V_0)}}{\hbar}$；
- 双曲正弦变为普通正弦：$\sinh(\kappa a) \to -i \sin(k_2 a)$；
- 透射系数变为：
  $$T = \frac{1}{1 + \dfrac{V_0^2}{4E(E - V_0)} \sin^2(k_2 a)}$$

### 共振完全透射条件（Ramsauer-Townsend 效应）：
当 $\sin(k_2 a) = 0$ 时，即势垒宽度满足半波长的整数倍：
$$k_2 a = n\pi \implies a = n \frac{\lambda_2}{2} \quad (n = 1, 2, 3, \dots)$$
此时 **$T = 1, R = 0$**！粒子能够 **100% 毫无阻碍地完全穿透势垒**，发生波的相消干涉！

## ⚠️ 五、 避坑手记与高分要诀

1. **透射波不要写错项**：区域 III 只有向右透射的 $T' e^{ikx}$，**绝对不能写 $e^{-ikx}$**（因为势垒右侧没有波源或反射界面）。
2. **几率流密度含速度因子的陷阱**：若势垒两侧的势能不相等（如阶梯势，左侧 $V=0$，右侧 $V=V_1 \neq 0$），则透射系数为 $T = \frac{v_2}{v_1} |T'|^2 = \frac{k_2}{k_1}|T'|^2$！**切勿漏掉波矢比值 $\frac{k_2}{k_1}$**！
3. **书写满分采分点**：大题推导时，在求出 $T$ 之后，一定要补写一句：*“因为 $R + T = 1$，这体现了体系在定态散射过程中的全空间几率流守恒”*。

# 811量子力学考点攻坚卡片：一维阶梯势垒散射与几率流守恒

## 一、 核心物理模型
* **势场分布**：$V(x) = \begin{cases} 0, & x < 0 \quad (\text{区域 I}) \\ V_0, & x > 0 \quad (\text{区域 II}) \end{cases}$，粒子能量 $E > V_0$。
* **波函数行波法设定**：
  * 区域 I ($x<0$): $\psi_I(x) = e^{ik_1 x} + R' e^{-ik_1 x}$ （包含振幅为 1 的入射波和振幅为 $R'$ 的反射波）
  * 区域 II ($x>0$): $\psi_{II}(x) = T' e^{ik_2 x}$ （仅包含振幅为 $T'$ 的透射波）
* **波数定义**：
  * $k_1 = \frac{\sqrt{2mE}}{\hbar}$
  * $k_2 = \frac{\sqrt{2m(E-V_0)}}{\hbar}$

## 二、 核心推导步骤骨架
1. **边界条件匹配**：
   * 连续性条件 $\psi_I(0) = \psi_{II}(0) \implies 1 + R' = T'$
   * 一阶导数连续 $\psi_I'(0) = \psi_{II}'(0) \implies ik_1(1 - R') = ik_2 T'$
2. **振幅求解**：
   * 反射振幅：$R' = \frac{k_1 - k_2}{k_1 + k_2}$
   * 透射振幅：$T' = \frac{2k_1}{k_1 + k_2}$
3. **几率流密度与系数转换**：
   * 几率流密度定义：$J = \frac{\hbar}{2mi} \left( \psi^* \frac{\partial \psi}{\partial x} - \psi \frac{\partial \psi^*}{\partial x} \right)$
   * 反射系数：$R = |R'|^2 = \left(\frac{k_1 - k_2}{k_1 + k_2}\right)^2$
   * 透射系数（含速度/波数修正）：$T = \frac{k_2}{k_1} |T'|^2 = \frac{4k_1 k_2}{(k_1 + k_2)^2}$
4. **几率流守恒验证**：
   * $R + T = \frac{(k_1 - k_2)^2 + 4k_1 k_2}{(k_1 + k_2)^2} = \frac{(k_1 + k_2)^2}{(k_1 + k_2)^2} = 1$

## 三、 易错踩坑清单（Warning）
* **陷阱 1（波函数多余项）**：区域 II 因为没有来自右侧的反射或入射，切勿多写 $B e^{-ik_2 x}$ 终态项。
* **陷阱 2（透射系数漏乘速度比）**：计算透射系数 $T$ 时，绝不能直接等于 $|T'|^2$，必须乘以两区域的几率流密度比（即波数比 $\frac{k_2}{k_1}$），因为势垒改变了粒子的传播速度！
* **陷阱 3（能量条件审题）**：本题限定 $E > V_0$（阶梯势垒），若考题变为 $E < V_0$（势垒隧穿），波数 $k_2$ 将变为纯虚数，波函数转为衰减的指数函数，切勿混淆。
