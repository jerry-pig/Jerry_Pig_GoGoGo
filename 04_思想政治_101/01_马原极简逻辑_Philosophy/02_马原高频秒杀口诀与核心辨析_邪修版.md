## ⚡ 一、 马原核心定性与黄金命题口诀

### 1. 科学社会主义与政党
- **科学社会主义的核心命题**：`【是2必】` $\to$ **资本主义必然灭亡，社会主义必然胜利**。
- **马恩建立的第一个无产阶级政党**：**共产主义者同盟**（1847年建立）。
- **马克思主义的基石 / 辩证唯物主义最基本最核心的观点**：**世界的物质统一性原理**。

### 2. 政治经济学两大核心辨析（高危混淆点！）
- **理解政治经济学的枢纽**：`【牢二枢纽】` $\to$ **劳动二重性理论**（具体劳动创造使用价值，抽象劳动形成价值）。
- **马克思经济学说的核心内容和基石**：**剩余价值理论**（揭示资本主义剥削的秘密）。
- ⚠️ **避坑陷阱**：
  - 题目问“枢纽” $\to$ 必选【劳动二重性】；
  - 题目问“核心内容与基石” $\to$ 必选【剩余价值理论】。

### 3. 认识论与实践观的绝对铁律
- **辩证唯物主义认识论第一的和基本的观点**：**实践的观点**。
- ❌ **绝对错误说法**：
  - “实践符合理论” （错！是**理论符合实际/实践**）；
  - “用实践套理论” （错！这是**本本主义/教条主义**）；
  - “真理是不可被检验的” （错！实践是检验真理的唯一标准）。
- ✅ **正确说法**：**用实践检验和发展理论** $\to$ 马克思主义中国化时代化。

### 4. 唯物史观核心主导力量
- **社会历史发展的决定力量 / 人类社会存在和发展的基础**：**物质资料生产方式**（生产力 + 生产关系）。
- **社会发展的最终决定力量**：**生产力**。
- **推动社会发展的根本动力**：**社会基本矛盾**（生产力与生产关系的矛盾、经济基础与上层建筑的矛盾）。
- **阶级社会发展的直接动力**：**阶级斗争**。
- **历史的创造者**：**人民群众**（绝不是个别英雄人物！个别人物只能起到加速或延缓作用）。

## 🎯 二、 马原辩证法对立统一“关系型”选择题秒杀表

考研政治多选题遇到“A 与 B 的关系”时，牢记以下**反向排雷口诀**：

| 关系对子 | 正确表述（选） | 错误干扰项（秒排） |
| :--- | :--- | :--- |
| **物质 vs 意识** | 物质决定意识，意识对物质具有能动反作用 | 意识决定物质；意识直接创造物质 |
| **实践 vs 认识** | 实践是认识的来源、动力、目的和唯一检验标准 | 认识先于实践；书本知识是第一来源 |
| **绝对真理 vs 相对真理**| 真理是绝对性与相对性的辩证统一，相互包含 | 绝对真理与相对真理相互对立、不可转化 |
| **主观能动性 vs 客观规律**| 尊重客观规律是发挥主观能动性的前提 | 发挥能动性可以改变/创造客观规律 |
| **感性认识 vs 理性认识**| 感性认识是理性认识的基础，理性认识依赖于感性认识 | 理性认识可以脱离感性认识直接产生 |
