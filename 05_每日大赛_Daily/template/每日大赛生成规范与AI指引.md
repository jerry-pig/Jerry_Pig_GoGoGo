# 每日大赛 v6.0 生成规范与 AI 指引

## 🧠 设计哲学 (Cognitive Science)
v6.0 模板彻底摒弃了“单一大题”模式，采用了基于最新认知科学的训练结构。
1. **交错练习 (Interleaving)**：Section A 必须同时包含微积分和线性代数的基础计算。
2. **掌握学习 (Mastery Learning)**：基础不牢，地动山摇。Section A 是每天的基石。
3. **直觉降维 (Dual-Coding/Intuition)**：Section B 专攻量子力学物理图像，绝不涉及复杂计算。
4. **多巴胺激励 (Dopamine Micro-Progress)**：每日结算 XP 奖励。

## ⚠️ 生成守则 (AI 必读)
1. **绝对对齐宏观蓝图**：出题前，必须读取 `00_Dashboard_作战指挥中心/16周宏观作战蓝图` 中当前的 Phase 阶段文件。**绝不允许超纲出题！**
2. **Section A (肌肉记忆)**：出 3 道题。2 道高数计算（如积分、极限、行列式），1 道基础微分方程或基础矩阵。
3. **Section B (概念闪击)**：出 2 道题。考察波函数意义、薛定谔方程图像、对易子物理意义等。
4. **Section C (核心母题)**：出 1 道标准考研难度的基础模型大题。必须分步设问（(1)写出哈密顿量, (2)求本征态...）。
5. **Section D (极限深渊)**：出 1 道极具挑战的题（如 2023 考研真题超纲部分），标记为选做。
6. **提供完整严密的解析 (Section E)**。

## 🎁 奖励结算 (XP System)
在 Section F，请为用户留出 XP 结算区域。例：
- Section A 基础全对：+30 XP
- Section C 核心拿下：+50 XP
